# 우주 정화 대전 · ORBIT

Vite + TypeScript + Three.js로 만든 PC용 3:3 우주 쓰레기 정화 게임입니다. 실제 플레이어 1명과 AI 5명이 180초 동안 경쟁합니다. 게임 서버나 계정은 필요하지 않습니다.

## 실행

Node.js 22.18 이상이 필요합니다. 의존성은 잠금 파일로 고정되어 있습니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 Chrome 또는 Edge에서 여세요. 기본 주소는 `http://127.0.0.1:5173`이며, 포트가 사용 중이면 Vite가 다음 포트를 사용합니다. WebGL과 하드웨어 가속이 필요합니다.

```sh
npm test         # Node.js 기본 테스트 러너로 게임 규칙 검사
npm run build   # TypeScript 검사 + 정적 파일 생성
npm run preview # dist 폴더의 배포 빌드 실행
```

`dist/`를 정적 호스팅에 올릴 수도 있습니다. 게임과 그래픽은 브라우저에서 실행되며, 외부 모델이나 이미지 파일은 사용하지 않습니다. Google Fonts 연결이 안 되면 시스템 글꼴을 사용합니다.

## 조작

| 조작 | 기능 |
| --- | --- |
| WASD | 화면 방향을 기준으로 이동합니다. 대각선 이동속도도 같습니다. |
| Q를 길게 누르기 | 가까운 쓰레기를 1초에 1개씩 청소합니다. 움직이면 청소를 취소합니다. |
| 마우스 | 상대 구역의 착탄 지점을 지정합니다. 주황색 조준점으로 표시합니다. |
| E | 경계선에서 4.2 이내일 때 쓰레기를 투척합니다. 자원 1개와 쿨타임 3초가 필요합니다. |
| R | 선택한 캐릭터의 고유 스킬을 사용합니다. |
| Esc | 경기를 일시정지하거나 다시 진행합니다. |

창이 포커스를 잃거나 다른 탭으로 이동하면 자동으로 일시정지합니다. 하단 E/R 버튼으로도 투척과 스킬을 사용할 수 있습니다. 한글 입력 상태에서도 `KeyboardEvent.code`를 기준으로 조작합니다.

## 구현 기능

- 시작 화면 → 캐릭터 선택 → 첫 경기 튜토리얼 → 카운트다운 → 180초 경기 → 결과 및 다시하기를 제공합니다.
- 고정 쿼터뷰 경기장, 로우폴리 우주 대원 6명, 팀 이름표, 이동 및 청소 애니메이션, 빛 입자와 효과음을 제공합니다.
- 블루팀은 플레이어와 AI 2명, 레드팀은 AI 3명으로 구성됩니다. 각 팀은 가디언·블래스터·클리너를 하나씩 사용합니다.
- 캐릭터는 자기 구역에서만 이동합니다. 최초 쓰레기 30개씩을 같은 위치에 대칭으로 배치합니다. 네 가지 쓰레기의 오염량은 모두 1입니다.
- 매 16초마다 각 팀에 기본 쓰레기 12개를 같은 위치에 대칭으로 추가합니다. 경기 마지막까지 청소할 대상을 공급하며, 다음 유입 시간을 표시합니다.
- 정화율은 `clamp(100 × (1 - 현재 쓰레기 수 / 30), 0, 100)`으로 계산합니다. 유입되거나 투척된 쓰레기도 오염량에 포함됩니다.
- 자원은 1개로 시작하며 최대 5개입니다. 기본 쓰레기 3개를 청소하면 자원 1개를 얻습니다. 상대 투척과 오염 폭탄으로 생긴 쓰레기는 자원을 주지 않습니다.
- 투척은 포물선으로 날아가 상대 구역에 쓰레기를 생성합니다. 원거리 스킬은 경계선까지 이동하지 않아도 사용할 수 있습니다.
- 가디언은 경계선 근처에서 반사막을 설치합니다. 반사막은 설치 지점의 앞뒤 4.5 범위를 5초간 방어하고, 일반 투척과 오염 폭탄을 반사합니다. 쿨타임은 15초입니다.
- 블래스터는 자원 2개로 오염 폭탄을 발사해 쓰레기 5개를 생성합니다. 쿨타임은 15초입니다.
- 클리너는 반경 3.8 안에 있는 쓰레기를 최대 3개 즉시 제거합니다. 쿨타임은 8초입니다.
- AI는 이동·청소·공격·스킬에 플레이어와 같은 규칙을 사용합니다. 청소 중인 쓰레기를 예약하므로 다른 캐릭터가 중복 청소하거나 흡입하지 않습니다.
- 180초 종료 시 정화율로 승리 또는 무승부를 판정합니다. 결과에는 양 팀 정화율, 플레이어 청소 수와 투척 횟수(일반 투척 + 오염 폭탄)를 표시합니다.

## 구조

- `src/game.ts`: 렌더링과 독립된 경기 규칙 및 AI입니다.
- `src/view.ts`: Three.js 경기장, 캐릭터, 효과와 마우스 좌표 변환입니다.
- `src/main.ts`: 화면 전환, 입력, 오디오, HUD와 게임 루프입니다.
- `src/style.css`: 게임 화면과 메뉴 스타일입니다.
- `tests/game.test.ts`: 규칙 및 180초 경기 시뮬레이션 테스트입니다.

## 검증과 범위

`npm test`는 대칭 초기화, 이동 제한, 청소 시간과 중복 예약, 자원 획득 및 상한, 투척 조건과 쿨타임, 폭탄 생성량, 보호막 반사와 지속 시간, 흡입 범위와 쿨타임, 유입 대칭, 정화율, 180초 종료 및 재시작을 검사합니다. 캐릭터 3종을 각각 플레이어로 선택한 전체 경기 시뮬레이션에서 AI 5명이 모두 청소하고, AI가 스킬 3종을 사용하며, 구역과 자원 제한을 지키는지도 확인합니다.

실제 멀티플레이, 게임방·초대코드, 로그인, 서버 통신, 대셔, 궁극기, 랭킹·상점·성장, 추가 경기장과 모바일 조작은 구현하지 않았습니다. AI는 규칙 기반이며 장애물 회피나 고급 협동 전술은 포함하지 않습니다. 그래픽은 외부 에셋 없이 코드로 생성하며, 고사양 애니메이션은 포함하지 않습니다. 실제 초등학생·중학생 대상의 재미와 난이도 평가는 별도로 진행해야 합니다.

브라우저 수동 검증에서는 시작·선택·튜토리얼 진입, WASD 이동, Q 청소, 캐릭터 3종의 R 스킬, E 투척, Esc 일시정지 및 재개, 경기 중 가이드, 실제 180초 종료 후 승패·통계 표시와 다시하기 초기화를 확인했습니다. 블래스터는 기본 쓰레기 3개를 청소해 자원 2개를 모은 뒤 오염 폭탄을 발사하는 과정까지 확인했습니다. 자동 테스트 18개가 통과했으며 TypeScript 검사와 배포 빌드도 통과했습니다.
